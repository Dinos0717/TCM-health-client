# 存疑清单

> 📌 **用途：** 客户对分析结论提出疑问或否定时，记录在此。由管理员（真人）审阅后给出辨证回答，Claude 不得在健康问题上擅自使用绝对化词汇答复。
>
> ⛔ **核心原则：** 这是关于人的健康。每一个疑问都需要辨证，不能用「一定」「肯定」「绝对是」来回答。

---

## 存疑记录

| 字段 | 说明 |
|------|------|
| 编号 | 自增序号 |
| 日期 | 疑问提出的时间 |
| 上下文 | 当时在讨论什么？Claude 给出了什么结论？ |
| 客户疑问 | 客户的原话，不做改写 |
| 涉及规则/体质判断 | 质疑触达了哪个核心判断？（体质辨证 / 性味分析 / 营养配比 / 排便辨证 / …） |
| 状态 | 🟡待管理员审阅 / 🟢已回复 / ⚪客户已接受 |
| 管理员回复 | 管理员给出的辨证回答 |
| 回复日期 | 管理员回复的日期 |
| 备注 | 是否需要更新 USER.md / 体质分析 等核心档案 |

---

## 示例

| 编号 | 日期 | 上下文 | 客户疑问 | 涉及判断 | 状态 | 管理员回复 | 回复日期 | 备注 |
|------|------|--------|----------|----------|------|------------|----------|------|
